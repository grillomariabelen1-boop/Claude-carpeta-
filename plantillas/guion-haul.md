# Guion — Haul (formato motor)

**Duración objetivo:** 20-35s · **Items:** 5-8 · **Frecuencia:** 2-3 / semana

---

## Antes de grabar

- [ ] Elegir la **prenda estrella** → va en el frame 1 Y anunciada como última
- [ ] Ordenar los items: la 2ª mejor arranca la tanda, la mejor cierra
- [ ] Probarse todo antes. Nada de decidir con la cámara prendida.
- [ ] Chequear luz: misma fuente en todos los planos

## Guion

```
┌─ 0-2s · GANCHO ─────────────────────────────────────┐
│ Prenda estrella YA PUESTA, en movimiento.           │
│ Sin bolsa. Sin caja. Sin cara hablando.             │
│                                                     │
│ Texto en pantalla: ______________________________   │
└─────────────────────────────────────────────────────┘

┌─ 2-4s · PROMESA + LOOP ABIERTO ─────────────────────┐
│ "Compré ___ cosas en ___ y la última                │
│  ______________________________"                    │
│                                                     │
│ El loop es obligatorio. Es lo que sostiene el video.│
└─────────────────────────────────────────────────────┘

┌─ 4s → final · ITEMS ────────────────────────────────┐
│ 3-4s por item. Corte duro entre uno y otro.         │
│                                                     │
│ Item 1: ____________________  precio: ______        │
│ Item 2: ____________________  precio: ______        │
│ Item 3: ____________________  precio: ______        │
│ Item 4: ____________________  precio: ______        │
│ Item 5: ____________________  precio: ______        │
│ Item 6: ____________________  precio: ______        │
│ Item 7: ____________________  precio: ______        │
│                                                     │
│ ÚLTIMO (el anunciado): _____________________        │
└─────────────────────────────────────────────────────┘

┌─ ÚLTIMO FRAME · CORTE SECO ─────────────────────────┐
│ Termina en el último item.                          │
│ Sin "chau". Sin "seguime". Sin pantalla final.      │
└─────────────────────────────────────────────────────┘
```

## Checklist antes de publicar

- [ ] El frame 1 muestra ropa puesta, no packaging
- [ ] El loop abierto está en el audio, no sólo en pantalla
- [ ] Ningún plano dura más de 4 segundos
- [ ] Precios en pantalla
- [ ] El último item es realmente el mejor
- [ ] Termina en corte seco
- [ ] Duración total ≤ 35s
