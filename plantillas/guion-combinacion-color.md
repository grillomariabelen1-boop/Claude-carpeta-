# Guion — Combinaciones de color (formato motor)

**Duración objetivo:** 12-20s · **Combis:** 3-5 · **Frecuencia:** 1-2 / semana

---

## Antes de grabar

- [ ] **Una sola base por video.** Dos bases confunden y bajan el share.
- [ ] Elegir la combi más inesperada → va en el frame 1
- [ ] Tener los nombres de color escritos antes de editar
- [ ] Mismo encuadre y misma distancia en todas las combis (la transición sólo
      funciona si no se mueve la cámara)

## Guion

```
Color base del video: ______________________

┌─ 0-2s · GANCHO ─────────────────────────────────────┐

┌─ 2-4s · PROMESA ────────────────────────────────────┐
│ "Con ___________ estas son las que sí"              │

┌─ 4s → final · COMBIS ───────────────────────────────┐
│ 3s por combinación. Transición DURA, nunca fade.    │
│ Nombre del color en pantalla, siempre.              │
│                                                     │
│ Combi 1: base + ______________                      │
│ Combi 2: base + ______________                      │
│ Combi 3: base + ______________                      │

│ Combi 5: base + ______________                      │
└─────────────────────────────────────────────────────┘

┌─ ÚLTIMO FRAME · CORTE SECO ─────────────────────────┐

└─────────────────────────────────────────────────────┘
```

## Checklist antes de publicar

- [ ] Una sola base
- [ ] La combi más rara está en el frame 1
- [ ] Nombres de color en pantalla en todas
- [ ] Transiciones duras, ningún fade
- [ ] Cámara fija, mismo encuadre
- [ ] Duración total ≤ 20s
