# Guion — Peinados con voice over

**Duración objetivo:** 20-30s · **Frecuencia:** 1 / semana

> **La regla de este formato: el VO tiene que agregar, no narrar.**
> Si dice lo que ya se ve, sobra y baja la retención.
>
> Mal: "ahora agarro un mechón".
> Bien: "acá va el truco: torcé hacia afuera, si vas hacia adentro se te abre
> en media hora".

---

## Antes de grabar

- [ ] Hacer el peinado una vez completo **antes** de grabar (el frame 1 es el
      resultado terminado)
- [ ] Definir **el truco**: el dato que no es obvio mirando → ______________
- [ ] Grabar el VO aparte y montarlo. El audio en vivo del proceso no sirve.
- [ ] Promesa concreta y medible (tiempo, duración, dificultad)

## Guion

```
┌─ 0-2s · GANCHO ─────────────────────────────────────┐
│ Peinado TERMINADO, girando / en movimiento.         │
│ Nunca arrancar con el pelo suelto.                  │
└─────────────────────────────────────────────────────┘

┌─ 2-4s · PROMESA CONCRETA ───────────────────────────┐
│ "Esto lo hago en ___ minutos y ___________________" │
│                                                     │
│ Concreta = tiempo, duración o dificultad.           │
│ "Queda divino" no es una promesa.                   │
└─────────────────────────────────────────────────────┘

┌─ 4-26s · PASO A PASO CON VO ────────────────────────┐
│ Paso 1: ______________________                      │
│   VO agrega: ______________________                 │
│                                                     │
│ Paso 2: ______________________                      │
│   VO agrega: ______________________                 │
│                                                     │
│ Paso 3: ______________________                      │
│   VO agrega: ______________________                 │
│                                                     │
│ EL TRUCO va acá: ______________________             │
└─────────────────────────────────────────────────────┘

┌─ 26-30s · CIERRE SANDWICH ──────────────────────────┐
│ Resultado final otra vez, mismo plano que el 0-2s.  │
│ Corte seco.                                         │
│                                                     │
│ La estructura sandwich (resultado → proceso →       │
│ resultado) sube rewatches.                          │
└─────────────────────────────────────────────────────┘
```

## Checklist antes de publicar

- [ ] Empieza y termina con el resultado (sandwich)
- [ ] El VO agrega en cada paso, no narra
- [ ] El truco está explícito
- [ ] VO grabado aparte, no en vivo
- [ ] Promesa concreta en los primeros 4s
- [ ] Corte seco
- [ ] Duración total ≤ 30s

## Descripción

```
[Nombre del peinado] en [X] minutos
El truco: [una línea]

#peinados #____ #____
```
