# Guion — Guía de compra (MOTOR DE SHARES)

**Duración objetivo:** 15-25s · **Items:** 3-5 · **Frecuencia:** 1 / semana (jueves)

Es el formato más compartible que producís: **515 shares con 648 likes (79%)**
en "Tiendas que sí o sí tenés que conocer" y **103%** en "Las 3 reglas de oro
antes de comprar", contra un ratio normal de 5-10%
([`../estrategia/10-datos-reales.md`](../estrategia/10-datos-reales.md),
hallazgo 6).

> **No es un haul.** Acá no se muestra lo que compraste: se muestra **dónde** y
> **qué mirar antes de pagar**. No requiere gastar un peso.

---

## Elegí el ángulo

- [ ] **Dónde comprar** — 3-5 lugares, con qué buscar en cada uno
- [ ] **Reglas antes de pagar** — las señales que miran los que saben
- [ ] **En qué me arrepentí de gastar** — la versión negativa; comenta más
- [ ] **Calzado** — zapatos y botas, sub-carril fijo y menos saturado
- [ ] **Cómo saber si una prenda es buena** — costura, tela, forro, caída

## Antes de grabar

- [ ] Tener los **nombres y los precios escritos** antes de editar
- [ ] Guardar el mejor lugar / la mejor regla para el **final**
- [ ] Conseguir la prueba visual: la prenda en la mano, la etiqueta, la costura
- [ ] Chequear que todo lo que decís se pueda **usar hoy** por quien mira

## Guion

```
Ángulo del video: ______________________________________

┌─ 0-2s · GANCHO — LA PRUEBA ─────────────────────────┐
│ La prenda conseguida + EL PRECIO en pantalla.       │
│ O el detalle que vas a explicar, en primer plano.   │
│ Nunca la fachada del local. Nunca vos hablando.     │
│                                                     │
│ Texto en pantalla: ______________________________   │
└─────────────────────────────────────────────────────┘

┌─ 2-4s · PROMESA + LOOP ABIERTO ─────────────────────┐
│ "___ lugares donde compro y el último                │
│  casi no lo cuento"                                 │
│                                                     │
│ o: "3 cosas que miro antes de pagar — la tercera    │
│     me ahorró un montón de plata"                   │
└─────────────────────────────────────────────────────┘

┌─ 4s → final · ITEMS ────────────────────────────────┐
│ 4-5s por item. Nombre EN PANTALLA, siempre.         │
│                                                     │
│ 1: ______________  qué buscar: ______  $ ______     │
│ 2: ______________  qué buscar: ______  $ ______     │
│ 3: ______________  qué buscar: ______  $ ______     │
│ 4: ______________  qué buscar: ______  $ ______     │
│                                                     │
│ ÚLTIMO (el mejor, el anunciado): ______________     │
└─────────────────────────────────────────────────────┘

┌─ ÚLTIMO FRAME · CORTE SECO ─────────────────────────┐
│ Termina en el último item. Sin "guardalo", sin      │
│ "compartilo": el video ya se comparte solo.         │
└─────────────────────────────────────────────────────┘
```

## Checklist antes de publicar

- [ ] Nombre de cada lugar / regla **en pantalla**
- [ ] Precios o rangos de precio en pantalla
- [ ] El frame 1 es la prueba, no el anuncio
- [ ] El loop abierto está en el audio
- [ ] El mejor va último
- [ ] Alguien podría actuar con esto **sin volver a mirar el video**
- [ ] Cero "tenés que" (frases prohibidas,
      [`../estrategia/07-pilares-y-voz.md`](../estrategia/07-pilares-y-voz.md))
- [ ] Duración total ≤ 25s

## Descripción

```
[Los lugares o las reglas, en lista corta — que se pueda leer sin el video]
1. ____
2. ____
3. ____

#dondecomprar #tiendas #compras
```

> La descripción en lista es lo que hace que el video se guarde. Es el único
> formato donde vale la pena repetir el contenido en texto.
